**Compile C++:**

&#x09;g++ "file name" -o "executable name"

&#x09;-o sets the name of the compiled file



**Compile C:**

&#x09;gcc "file name" -o "executable name"

&#x09;-o sets the name of the compiled file



**Remove Files:**

&#x09;rm -rf \* remove all files/folders in current file

&#x09;



**Create Log Files:**

&#x09;script -a -f \~/wsl\_session.log



**Run Executable from input file to output file:**

&#x09;./"executable" < "input file" > "output file"



**Run Executable from file out to same file:**

&#x09;./"executable" < "input file" >> "output file"
